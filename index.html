Variablen & Ausgabe

        
Zuweisungen schreibt man mit :=. Kommentare beginnen mit //.
          Das Wort sei vor einer Zuweisung ist erlaubt, aber nicht nötig.

        
x    := 42
pi   := 3.14
name := "PseudoCode"

ausgabe(x)
ausgabe("Wert: " + text(x))

      


      

        
Eingabe

        
eingabe(…) liefert immer eine Zeichenkette. Mit zahl(…) wird daraus eine Zahl.
          Hier im Interpreter tippst du die Eingabe rechts unten ein.

        
name  := eingabe("Wie heißt du? ")
alter := zahl(eingabe("Wie alt bist du? "))
ausgabe("Hallo " + name + ", nächstes Jahr bist du " + text(alter + 1))

Schleifen

        
// Solange-Schleife
solange x > 0 tue
    ausgabe(x)
    x := x - 1
endesolange

// Zählschleife (C-Stil)
fuer i := 0; i < 5; i++ tue
    ausgabe(i)
endefuer

// Bereichsschleife (Ende inklusive), Schrittweite optional
fuer i von 1 bis 10 schrittweite 2 tue
    ausgabe(i)
endefuer

      


      

        
Funktionen

        
funktion addiere(a, b)
    rueckgabe a + b
endefunktion

ergebnis := addiere(3, 4)
ausgabe(ergebnis)   // 7

        
Funktionen dürfen vor oder nach ihrem Aufruf definiert werden und sich selbst aufrufen (Rekursion).

      


      

        
Listen

        
Indizes beginnen bei 0.

        
zahlen := liste(10, 3, 7)
zahlen.hinzufuegen(42)
zahlen[0] := 99
ausgabe(zahlen[0])          // 99
ausgabe(laenge(zahlen))     // 4
zahlen.sortieren()
letzter := zahlen.pop()

        

          
MethodeWirkung

          
            
hinzufuegen(wert)Wert ans Ende anhängen

            
entfernen(index)Element an Position entfernen

            
einfuegen(index, wert)Wert an Position einfügen

            
pop()letztes Element entfernen und zurückgeben

            
sortieren()aufsteigend sortieren (nur Zahlen oder nur Texte)

            
umkehren()Reihenfolge umdrehen

Operatoren & Schlüsselwörter

        

          
PseudocodeBedeutung

          
            
:=Zuweisung

            
= oder ==   !=gleich, ungleich

            
< > <= >=Vergleiche

            
+ - * / %Rechnen, % = Rest der Division; + verbindet auch Texte

            
**Potenz, z. B. 2 ** n; rechtsassoziativ: 2 ** 3 ** 2 = 2 ** 9

            
und oder nichtLogische Verknüpfungen

            
wahr falschWahrheitswerte

            
i++ i--um 1 erhöhen / verringern

            
wenn … dann … sonstwenn … sonst … endewennVerzweigung

            
solange … tue … endesolangeKopfgesteuerte Schleife

            
fuer … tue … endefuerZählschleife (C-Stil oder von … bis … schrittweite)

            
funktion … endefunktion, rueckgabeFunktion mit Rückgabewert

          
        

        
ende funktioniert als universelles Blockende. Statt fuer, rueckgabe,
          laenge, hinzufuegen und einfuegen dürfen auch die Schreibweisen mit Umlaut verwendet werden.
